## Overview

Implement the main Windows Service class that provides the foundation for the license release service. This task involves creating a service that can be installed, started, stopped, and managed by Windows Service Manager.

## Technical Approach

### 1. Service Base Class Implementation
- Create `LicenseReleaseService` class inheriting from `ServiceBase`
- Implement required lifecycle methods: `OnStart`, `OnStop`, `OnPause`, `OnContinue`
- Add service name and display name configuration
- Implement graceful shutdown handling

### 2. Service Installation Support
- Create `ProjectInstaller` class for service installation
- Configure service account and startup type
- Add service description and recovery options
- Support for command-line installation arguments

### 3. Service Entry Point
- Implement `Main` method for service execution
- Add support for console mode during development
- Handle command-line arguments (install, uninstall, console)
- Implement service host factory pattern

### 4. Service State Management
- Track service state (running, stopped, paused)
- Implement status reporting mechanisms
- Add health check endpoint for monitoring
- Handle service exceptions gracefully

### Installation Support
```csharp
[RunInstaller(true)]
public class ProjectInstaller : Installer
{
    private ServiceProcessInstaller _processInstaller;
    private ServiceInstaller _serviceInstaller;

    public ProjectInstaller()
    {
        _processInstaller = new ServiceProcessInstaller
        {
            Account = ServiceAccount.LocalSystem
        };

        _serviceInstaller = new ServiceInstaller
        {
            ServiceName = "LicenseReleaseService",
            DisplayName = "License Release Service",
            Description = "Manages software license releases and monitoring",
            StartType = ServiceStartMode.Automatic
        };

        Installers.Add(_processInstaller);
        Installers.Add(_serviceInstaller);
    }
}
```
