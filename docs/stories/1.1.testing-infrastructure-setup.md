### Coding Standards
[Source: architecture.md#Coding Standards]
- **Test-Driven Development**: All functionality must include comprehensive tests
- **Mock-First Approach**: External dependencies must be mocked for unit testing
- **Async/Await Consistency**: All I/O operations must use async/await patterns
- **Dependency Injection**: All components must use dependency injection for testability
- **Configuration Management**: All configuration must be externalized
- **Error Handling**: All operations must include comprehensive error handling and logging
- **Resource Cleanup**: All IDisposable resources must be properly disposed

### Naming Conventions
[Source: architecture.md#Naming Conventions]
- **Test Classes**: `[ClassName]Tests` (e.g., `LicenseQueryEngineTests.cs`)
- **Test Methods**: `[MethodName]_[Scenario]_[ExpectedResult]` (e.g., `QueryLicenses_ValidResponse_ReturnsLicenseInfo()`)
- **Mock Classes**: `Mock[InterfaceName]` (e.g., `MockILicenseManager.cs`)
- **Test Data**: `[Feature]_[Scenario]_[Data]` (e.g., `LicenseQuery_SuccessResponse.json`)
- **Test Fixtures**: `[ComponentName]TestFixture` (e.g., `LicenseManagementTestFixture.cs`)

### Architecture Constraints
[Source: architecture.md#Starter Template or Existing Project]
- **Brownfield Enhancement**: This is a testing framework addition to existing production service
- **No Production Code Changes**: Testing framework must not modify existing service functionality
- **Windows Service Compatibility**: Tests must work without actual Windows Service installation
- **.NET 9.0**: Must maintain compatibility with existing framework version

### Testing Strategy
[Source: architecture.md#Testing Strategy]
- **Testing Pyramid**: Unit Tests (60%), Integration Tests (25%), Performance Tests (10%), E2E Tests (5%)
- **Test Organization**: Separated by type (Unit, Integration, Performance) with shared infrastructure
- **Mock Environment**: Create mock license server environments for isolated testing
- **CI/CD Integration**: Automated test execution with reporting and coverage collection
