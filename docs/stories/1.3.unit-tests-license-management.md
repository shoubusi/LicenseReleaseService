### Coding Standards
[Source: architecture/coding-standards.md]
- **Test-Driven Development**: All functionality must include comprehensive tests
- **Mock-First Approach**: External dependencies must be mocked for unit testing
- **Async/Await Consistency**: All I/O operations must use async/await patterns
- **Dependency Injection**: All components must use dependency injection for testability
- **Error Handling**: All operations must include comprehensive error handling and logging
- **Resource Cleanup**: All IDisposable resources must be properly disposed
- **Performance Monitoring**: All operations must include performance monitoring and metrics collection

### Test Organization and Naming Conventions
[Source: architecture/coding-standards.md#Naming Conventions]
- **Test Classes**: `[ClassName]Tests` (e.g., `LicenseQueryEngineTests.cs`)
- **Test Methods**: `[MethodName]_[Scenario]_[ExpectedResult]` (e.g., `QueryLicenses_ValidResponse_ReturnsLicenseInfo()`)
- **Mock Classes**: `Mock[InterfaceName]` (e.g., `MockILicenseManager.cs`)
- **Test Data**: `[Feature]_[Scenario]_[Data]` (e.g., `LicenseQuery_SuccessResponse.json`)
- **Test Fixtures**: `[ComponentName]TestFixture` (e.g., `LicenseManagementTestFixture.cs`)

### Process Execution Mocking Strategy
[Source: architecture/testing-strategy.md#License Management Testing]
License management tests must mock external process execution:
- **Mock Process Executor**: Use configurable process executor for real/mock process switching
- **Process Result Simulation**: Mock process execution results (success, failure, timeout)
- **Command Line Validation**: Verify correct lmutil.exe command generation
- **Exit Code Handling**: Test various exit codes and error scenarios
- **Output Stream Capture**: Test standard output and error stream handling

- **Cache Performance**: Cache hit/miss performance and memory usage

### Error Handling Scenarios
License management testing must cover these error scenarios:
- **Network Failures**: License server unreachable or network timeouts
- **Process Execution Failures**: lmutil.exe process crashes or hangs
- **Invalid License Output**: Malformed or unexpected lmstat output formats
- **Permission Errors**: Insufficient permissions to execute license queries
- **Resource Exhaustion**: Memory or CPU constraints during license operations

- **Configuration Integration**: Ensure license management components work with existing configuration system
